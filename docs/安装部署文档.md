# 基于大数据的天气数据分析与可视化系统 - 安装部署文档

## 一、环境要求

### 1.1 硬件要求

**最低配置（开发/演示）：**
- CPU: 4核心
- 内存: 16 GB
- 硬盘: 100 GB 可用空间

**推荐配置（生产）：**
- CPU: 8核心或以上
- 内存: 32 GB 或以上
- 硬盘: 500 GB 可用空间（SSD）

### 1.2 操作系统

- Windows 10/11 (64位)
- Ubuntu 20.04/22.04 LTS
- CentOS 7/8

### 1.3 软件依赖

**必需组件：**
- Python 3.8+
- Node.js 16+
- MySQL 8.0+
- Java 11+ (用于 Hadoop/Spark/Flink)

**大数据组件：**
- Hadoop 3.3+
- Apache Spark 3.3+
- Apache Flink 1.17+
- Apache Kafka 3.0+

## 二、安装步骤

### 2.1 安装 Python 环境

#### Windows:

1. 下载 Python 3.8+
   - 访问: https://www.python.org/downloads/
   - 下载 Windows installer (64-bit)

2. 安装 Python
   ```bash
   # 勾选 "Add Python to PATH"
   # 安装完成后验证
   python --version
   pip --version
   ```

3. 安装项目依赖
   ```bash
   cd backend
   pip install -r requirements.txt
   ```

#### Linux:

```bash
# Ubuntu/Debian
sudo apt update
sudo apt install python3.8 python3-pip

# CentOS/RHEL
sudo yum install python38 python38-pip

# 安装项目依赖
cd backend
pip3 install -r requirements.txt
```

---

### 2.2 安装 MySQL 数据库

#### Windows:

1. 下载 MySQL
   - 访问: https://dev.mysql.com/downloads/installer/
   - 下载 MySQL Installer

2. 安装 MySQL
   - 选择 "Developer Default"
   - 设置 root 密码
   - 端口: 3306

3. 创建数据库
   ```sql
   mysql -u root -p
   CREATE DATABASE weather_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   ```

#### Linux:

```bash
# Ubuntu/Debian
sudo apt install mysql-server
sudo mysql_secure_installation

# CentOS/RHEL
sudo yum install mysql-server
sudo systemctl start mysqld
sudo systemctl enable mysqld

# 创建数据库
mysql -u root -p
CREATE DATABASE weather_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

4. 初始化数据表
   ```bash
   cd backend
   python data_storage/mysql_manager.py
   ```

---

### 2.3 安装 Hadoop (HDFS)

#### Windows:

1. 下载 Hadoop Windows 版本
   - 访问: https://github.com/steveloughran/winutils
   - 下载对应版本的 winutils.exe 和 hadoop.dll

2. 配置环境变量
   ```bash
   # 设置 HADOOP_HOME
   setx HADOOP_HOME "C:\hadoop"
   setx PATH "%PATH%;%HADOOP_HOME%\bin"
   ```

3. 配置 Hadoop
   - 编辑 `hadoop/etc/hadoop/core-site.xml`
   - 编辑 `hadoop/etc/hadoop/hdfs-site.xml`

4. 格式化 NameNode
   ```bash
   hadoop namenode -format
   ```

5. 启动 HDFS
   ```bash
   start-dfs.cmd
   ```

#### Linux:

```bash
# 下载 Hadoop
wget https://dlcdn.apache.org/hadoop/common/hadoop-3.3.6/hadoop-3.3.6.tar.gz
tar -xzf hadoop-3.3.6.tar.gz
sudo mv hadoop-3.3.6 /usr/local/hadoop

# 配置环境变量
echo 'export HADOOP_HOME=/usr/local/hadoop' >> ~/.bashrc
echo 'export PATH=$PATH:$HADOOP_HOME/bin:$HADOOP_HOME/sbin' >> ~/.bashrc
source ~/.bashrc

# 配置 Hadoop
# 编辑 core-site.xml, hdfs-site.xml, yarn-site.xml

# 格式化 NameNode
hdfs namenode -format

# 启动 HDFS
start-dfs.sh
```

### 2.4 安装 Apache Spark

#### Windows:

1. 下载 Spark
   - 访问: https://spark.apache.org/downloads.html
   - 下载 "Pre-built for Apache Hadoop"

2. 解压到指定目录
   ```bash
   # 解压到 C:\spark
   ```

3. 配置环境变量
   ```bash
   setx SPARK_HOME "C:\spark"
   setx PATH "%PATH%;%SPARK_HOME%\bin"
   ```

#### Linux:

```bash
# 下载 Spark
wget https://dlcdn.apache.org/spark/spark-3.5.0/spark-3.5.0-bin-hadoop3.tgz
tar -xzf spark-3.5.0-bin-hadoop3.tgz
sudo mv spark-3.5.0-bin-hadoop3 /usr/local/spark

# 配置环境变量
echo 'export SPARK_HOME=/usr/local/spark' >> ~/.bashrc
echo 'export PATH=$PATH:$SPARK_HOME/bin' >> ~/.bashrc
source ~/.bashrc

# 测试 Spark
spark-submit --version
```

### 2.5 安装 Apache Kafka

#### Windows:

1. 下载 Kafka
   - 访问: https://kafka.apache.org/downloads
   - 下载二进制包

2. 解压到指定目录

3. 启动 Zookeeper
   ```bash
   cd kafka
   bin\windows\zookeeper-server-start.bat config\zookeeper.properties
   ```

4. 启动 Kafka
   ```bash
   bin\windows\kafka-server-start.bat config\server.properties
   ```

#### Linux:

```bash
# 下载 Kafka
wget https://dlcdn.apache.org/kafka/3.6.0/kafka_2.13-3.6.0.tgz
tar -xzf kafka_2.13-3.6.0.tgz
sudo mv kafka_2.13-3.6.0 /usr/local/kafka

# 启动 Zookeeper
cd /usr/local/kafka
bin/zookeeper-server-start.sh config/zookeeper.properties &

# 启动 Kafka
bin/kafka-server-start.sh config/server.properties &

# 创建 Topics
bin/kafka-topics.sh --create --topic weather-realtime --bootstrap-server localhost:9092
bin/kafka-topics.sh --create --topic weather-historical --bootstrap-server localhost:9092
bin/kafka-topics.sh --create --topic weather-alerts --bootstrap-server localhost:9092
bin/kafka-topics.sh --create --topic weather-predictions --bootstrap-server localhost:9092
```

## 三、配置文件

### 3.1 后端配置

编辑 `backend/config/config.yaml`:

```yaml
# 数据库配置
database:
  mysql:
    host: "localhost"
    port: 3306
    username: "root"
    password: "你的密码"
    database: "weather_db"

# Hadoop HDFS 配置
hadoop:
  hdfs:
    namenode: "localhost"
    port: 9000
    user: "hadoop"

# Kafka 配置
kafka:
  bootstrap_servers:
    - "localhost:9092"

# 气象数据源配置（需要注册获取 API Key）
weather_data_sources:
  qweather:
    api_key: "你的和风天气API密钥"
  
  openweathermap:
    api_key: "你的OpenWeatherMap API密钥"
```

### 3.2 申请数据源 API

**和风天气（主要数据源）：**
1. 访问: https://dev.qweather.com/
2. 注册账号
3. 创建应用获取 API Key
4. 免费版本足够开发使用

**OpenWeatherMap（备用数据源）：**
1. 访问: https://openweathermap.org/api
2. 注册账号
3. 获取 API Key

## 六、常见问题

### 6.1 端口占用

如果端口被占用，可以修改配置文件中的端口号：
- MySQL: 默认 3306
- Flask API: 默认 5000
- 前端: 默认 5173
- Hadoop NameNode: 默认 9000/9870
- Kafka: 默认 9092

### 6.2 Hadoop 权限问题

Windows 下可能遇到权限问题：
```bash
# 以管理员身份运行命令行
# 或修改 hdfs-site.xml 添加:
<property>
  <name>dfs.permissions.enabled</name>
  <value>false</value>
</property>
```

### 6.3 Python 依赖安装失败

使用镜像源加速：
```bash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 6.4 数据采集失败

检查：
1. API Key 是否正确配置
2. 网络是否可以访问数据源
3. 查看日志文件: `backend/logs/`

## 七、生产环境部署建议

### 7.1 使用 Docker 部署

```bash
# TODO: 提供 Docker Compose 配置
docker-compose up -d
```

### 7.2 性能优化

1. **MySQL 优化**
   - 增大 `innodb_buffer_pool_size`
   - 启用慢查询日志

2. **Hadoop 优化**
   - 调整 HDFS 块大小
   - 增加 DataNode 节点

3. **Spark 优化**
   - 调整 executor 内存和核心数
   - 启用动态资源分配

4. **Kafka 优化**
   - 增加分区数
   - 调整副本因子

### 7.3 监控和日志

- 使用 Prometheus + Grafana 监控系统指标
- 使用 ELK Stack 集中管理日志
- 配置告警规则
